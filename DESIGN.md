# LittleNest (Sweet Baby's) Design Specification

## 1. Unified Brand Identity & Visual Language
Both the Storefront and the Admin Console share the same warm, boutique baby brand aesthetics:
- **Palette**: Signature warm cream backdrop (`#fdfbf7`), rose petal pink gradient (`from-pink-500 via-rose-400 to-rose-500`), fresh emerald for verified status, soft amber for alerts, and deep slate typography (`#1e293b`).
- **Logo**: Official high-resolution transparent logo `/logo_transparent.png`.
- **Card Surfaces**: Crisp white cards with ultra-soft pink border accents (`bg-white border-pink-100/80 rounded-3xl shadow-sm`).

## 2. Admin Console UX
- **Theme**: Cohesive pastel boutique styling with light background, matching header navigation, smooth pill badges, and friendly accessible modal drawers.
- **Components**:
  - Live KPI statistics cards with soft tinted backgrounds.
  - Search & filter bars with quick tags.
  - Multi-image file drag-and-drop uploader.
  - Immediate inline order status updates.
